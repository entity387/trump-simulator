# v0.9.2 — Secret Developer Panel

Access is accepted only while the unobstructed home menu is open.

Sequence:
UP, UP, DOWN, DOWN, LEFT, RIGHT, LEFT, RIGHT, B, A, ENTER

Then enter the developer access code and submit it.

Current dev tools:
- View the campaign map concept overview without playing through the game.
- Quick-start any of the six current gameplay stages.
- Dev test sessions do not overwrite the normal campaign save.

UI readability change:
- Main menu, pause, settings, credits, game-over, loading, developer-code and developer panels now use opaque panel backgrounds instead of see-through panels.
