Trump Simulator v1.0.1 — Multiplayer + Visual Fix

FIXED
- Main MULTIPLAYER button opens a stable multiplayer hub instead of directly hiding the menu.
- Online Host / Join is an option inside that hub.
- If the online UI script is missing, the player is returned to the multiplayer hub instead of a blank screen.
- Debate audience cameras are raised, with tiered seating for clearer sightlines.
- Moderator camera is raised and the monitor is moved lower/left so it no longer blocks the view.
- Debate walls/floor/stage/desks/podiums/chairs now use original textures and non-grey material tints.
- Crisis Room walls/floor/desks/table/chairs now use original plaster, rug, wood and leather textures.
- Crisis role cameras are raised slightly for clearer station views.
- 3D console buttons are substantially smaller.
- Missing Oval Office visual-reboot background assets are included.
- GitHub build refuses to continue if critical multiplayer/background texture files are absent.
- Version bumped to 1.0.1 for installer/updater replacement.

ONLINE NETWORKING NOTE
The multiplayer hub/menu and local map/role previews are fixed here. Actual Internet Host/Join still depends on the EOSG plugin, Epic Online Services credentials, and a deployed join-code backend. Those external credentials/services are not embedded in this patch.
