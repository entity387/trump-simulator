# v0.9.3 — Translucent readable menu pass

This build replaces the heavy opaque menu look with a more stylish but still readable presentation.

## Changed
- Main menu, pause menu, settings, credits, dev code screen, dev panel and game-over panel now use tinted translucent panels.
- Added a subtle full-screen dark backdrop behind open menus so scene detail stays visible but text remains easy to read.
- Menu buttons now use custom styled normal / hover / pressed / focus states for readability and a cleaner feel.
- Existing secret developer panel flow remains unchanged.

## Design goal
Not fully transparent.
Not fully opaque.
Readable and still part of the scene.
