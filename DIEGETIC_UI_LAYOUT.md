# Diegetic UI Layout

The Desktop Edition should treat the 3D office as the gameplay interface.

## Center
**Launch Control Monitor**
- bombs
- power per press
- lifetime progression
- current stage

## Right side
**Threat Monitor**
- enemy pressure
- threat severity

**Paper Deadline Display**
- document state
- countdown

**Crisis Monitor**
- stage 5 crisis state

## Left side
**Phone Display**
- incoming caller
- active caller
- call/ring countdown

**Alarm Monitor**
- stage 6 alarm state

**Upgrade Terminal**
- wall-mounted physical touchscreen
- opens upgrade purchase panel

## Walls
**News / Approval screen**
- approval rating

**Office Status screen**
- chaos level

## Launch station
**Button Heat display**
- current heat
- overheat warning

## Screen-space UI allowed
Only:
- pause/settings/main menu
- subtitles
- short transient status messages
- upgrade terminal overlay while actively using the terminal

This layout should survive the later high-detail modeling pass.
