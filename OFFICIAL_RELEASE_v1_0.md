# Trump Simulator 1.0.0 — Official Release Package

This package promotes the current project to version 1.0.0 and adds the
official Windows self-update flow.

Highlights:
- Official release version 1.0.0
- Same installer AppId retained for upgrades
- Automatic silent website update check
- Update Available popup
- HTTPS-only installer download
- SHA-256 verification before installer execution
- Silent Inno Setup upgrade launch
- Release builder automatically generates update.json
- Existing save files are not replaced by the installer
