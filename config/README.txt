ONLINE MULTIPLAYER CONFIG

1. Install and enable EOSG in Godot.
2. Copy eos_credentials.example.json to eos_credentials.json.
3. Fill in the values from the Epic Developer Portal.
4. Deploy backend/join-code-worker.
5. Put the Worker URL into project.godot under:
   trump_simulator/multiplayer/join_code_api

Do not commit or publicly post your real credential file.
