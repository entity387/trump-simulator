# First Run Checklist — v0.5

Open `project.godot` in Godot 4.7.x and run the project.

Check these in order:

1. Main menu appears.
2. New Game starts.
3. The old corner stats/meters do NOT appear.
4. Central 3D Launch Control monitor is readable and updates when pressing the button.
5. Threat Monitor changes after Stage 2.
6. Phone display shows caller name/countdown after Stage 3.
7. Paperwork display shows a countdown after Stage 4.
8. Wall Approval and Office Status screens update.
9. Button Heat display updates from Stage 4 onward.
10. Stage 5 Crisis screen and red-phone/folder interaction work.
11. Stage 6 Alarm screen and reset switch work.
12. Click the green Upgrade Terminal or press `U`.
13. Upgrade panel opens.
14. Game continues running while the Upgrade Terminal is open.
15. Escape closes the Upgrade Terminal before pausing.
16. Subtitles remain OFF by default.
17. Save, Continue and difficulty modes still function.

Because this environment cannot run Godot itself, this checklist is the first integration validation to perform in the editor.
